# Qoin version map

## Version 1 — Vector baseline

Branch: [`version-1-vector-baseline`](https://github.com/capiyo/Qoin-full-repo/tree/version-1-vector-baseline)

The retained architecture baseline: frontend clients, Drogon gateway, Axum-authoritative state/vector decisions, MongoDB persistence, and explicit research/risk boundaries. See the [Version 1 specification](https://github.com/capiyo/Qoin-full-repo/blob/version-1-vector-baseline/docs/versions/VERSION_1.md).

The current feature branch continues product and frontend development on this vector-only architecture. The active system uses the deterministic, explicitly versioned vector/strategy path.

## Safety

The system remains research/paper-only. The existing `docs/RISK_POLICY.md` remains binding. Live trading requires every gate to be implemented and independently verified plus explicit written user approval.
